# Security Policy

## Supported versions

- Current 3.x line: security fixes accepted
- Older versions: please upgrade

## Reporting a vulnerability

- Email: [kurt.kincaid@gmail.com](mailto:kurt.kincaid@gmail.com) with subject "Divinator security issue"
- Provide a minimal reproduction and impact assessment if possible
- We will acknowledge within 72 hours and coordinate a fix and disclosure timeline

## Dependencies

- Regular `npm audit` checks
- GitHub Advisory scanning enabled (CI planned)
